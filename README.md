# ej2-javascript-csp-example

The sample is a focused demonstration: a static HTML page that loads the Syncfusion Grid and related assets in a way compatible with strict CSP settings. It is intended for developers who need to validate or prototype Syncfusion UI behavior when inline execution is disallowed by policy.

> To learn more about Content Security Policy (CSP) and guidance for Syncfusion, see: https://ej2.syncfusion.com/javascript/documentation/common/troubleshoot/content-security-policy

## Features

- Demonstrates Syncfusion JavaScript Grid running under a strict CSP.
- Provides a minimal, static example (`index.html`) suitable for quick local testing.
- Shows a pattern for loading external scripts and styles without relying on inline script tags.
- Useful for verifying CSP headers and troubleshooting common CSP-related issues.

## Prerequisites

- A modern web browser (Chrome, Firefox, Edge, Safari) with CSP enforcement.
- No build tools are required; the example is a static HTML sample.

## Install & run

1. Clone or download the repository and open the project folder.
2. To test quickly, open `index.html` directly in your browser.
